# Habits

日々の生活習慣をタスク化し、努力を可視化する習慣トラッカー。

Duolingoの「毎日続く」構造を、自分の生活（筋トレ・読書・プログラミング・英語）に移植することが狙い。「できた / できてない」の2択で記録し、その日の達成度を円グラフで見える化する。

## MVP（このバージョン）のスコープ

- 7タスクを曜日に応じて表示
  - 筋トレ：胸（月）/ 背中（火）/ 肩+腕（木）/ 脚（日）
  - 読書10分 / プログラミング30分 / 英語学習15分（毎日）
- チェックボックスで「できた」を記録
- 記録はブラウザの localStorage に保存（リロードしても残る）
- その日の達成度をドーナツ円グラフで表示

## 技術スタック

## データモデル

タスクの定義（`Task`）と日々の実績（`DoneRecord`）を分離している。タスクを後から足し引きしても過去の実績が壊れないようにするため。

```
Task        : 何を・いつやるか（マスター）
DoneRecord  : ある日そのタスクをやったか（実績）
```

- `src/types.ts` — 型定義
- `src/tasks.ts` — タスクマスター
- `src/storage.ts` — localStorage 読み書き・日付ユーティリティ
